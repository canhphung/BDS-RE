# Operational and offline discovery evidence

Target SHA256: `69142612b2a87b0ff6d63f64dd0f07ca94d647b09659590fdadc0900af41c4ad`. Confidence: VERIFIED_BINARY for the following observations, not VERIFIED_RUNTIME. Reproduce focused outgoing calls with `reverse/scripts/index_elf.py`; machine-readable constants are in reverse/evidence/operational_constants.json. Raw disassembly remains ignored locally.

Full bootstrap ownership is not reconstructed.

- At 0x1817b35 the parser references string 0x281c710 (`default-player-permission-level`) and compares it to the key. The shorter spelling in the shipped file does not appear in the inspected key chain; it is not silently accepted as an alias.
